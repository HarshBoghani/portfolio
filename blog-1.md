LEVELS AND TOPICS (WITH RESOURCES)

This blog is about what topics are needed to achieve certain level/ranks in competitive coding with best hand-picked resources.

There are number of platforms for competitive coding, but this blog will be about levels of CodeForces .
1) Pupil
2) Specialist
3) Expert
(further levels will be discussed in future blogs)

Pupil (1200–1400)

First level of codeforces , this level does not require any knowledge about major data structures like Tree, Graphs.
Select any 1 good programming language you are familiar with, be it C++, Java or any other programming language.
Learn basics
-> Input/Output
-> Arrays
-> Strings
-> Loops etc.

Learn STL-collection
-> Vector
-> Set
-> Map etc.
(video: C++ Java)

Topics
-> Binary Search
-> Sliding Window
-> Basic Math (including Number Theory)
-> Bit Manipulation

Specialist(1400–1600)

Second level of codeforces , this level does require a bit knowledge about major data structures like Tree, Graphs. But not in depth basic knowledge of DFS,BFS is needed.
Interactive Problems are introduced mostly in 1400–1600 range.
Number Theory concepts like Sieve of Eratosthenes, Factors, Binary Exponentiation, Modular Arithmetic are essential.
(Note that Binary Tree traversals and algorithms are not often seen on codeforces, mostly Tree problems are having normal tree which can have more than 2 children nodes)

Topics

Expert(1600–1900)

Third level of codeforces, this level requires one major new topic which is Dynamic Programming along with some new algorithms of previously learned topics like trees, graphs etc.
Graphs
-> Shortest Paths
-> Topo sort
-> Bridges in graphs
(for these topics of graphs and trees you can explore USACO guide , CP algorithms, CPH handbook for blogs And for video explanation TakeUforward)

Trees
-> Tree diameter
-> DP on Trees

Dynamic Programming
-> Blog
-> Video explanation
